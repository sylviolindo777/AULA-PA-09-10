# StepUp Calçados

Loja virtual de calçados desenvolvida como projeto escolar do curso de
Desenvolvimento de Sistemas, simulando um e-commerce real com HTML, CSS e JavaScript.

## Funcionalidades
- [x] Catálogo de produtos
- [x] Filtros e busca
- [x] Carrinho de compras (salvo no navegador)
- [x] Checkout simulado (cupom e frete fictício)
- [x] Página de contato com validação

## Tecnologias
HTML5 · CSS3 · JavaScript (ES6+) · LocalStorage

## Estrutura do projeto
```
├── docs/   -> documentação (API, guia de uso, requisitos)
└── src/    -> código-fonte do site
```

## Como executar
1. Clone ou baixe o repositório
2. Abra `src/index.html` no navegador (ou use a extensão Live Server do VS Code)
